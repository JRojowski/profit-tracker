# Project documents

`docs-sync` keeps the documents in this list current. It reads only the list under `## Documents`.

Each bullet holds one repo-relative path in backticks and a one-line purpose.
`docs/repo-map.md` is always in the list.
To add a document, add a bullet. To remove a document, remove its bullet.

## Documents

- `docs/repo-map.md` — Where each part of the code is.
- `AGENTS.md` — The commands, the layout and the configuration values of the project.
- `docs/deployment.md` — How to deploy the tool to Azure.
- `docs/checklists/` — The manual test checklists of the user flows.
- `frontend/README.md` — The short guide to the frontend application.
