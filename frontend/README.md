# Profit Tracker frontend

The React application of Profit Tracker. The Go program in `../backend` embeds the production build.

See the root `CLAUDE.md` for the build, dev and test commands.

To add a shadcn/ui component, run `yes n | npx shadcn@latest add <component>`. The `yes n` keeps the components that already exist.

The conventions of this application are in `.claude/skills/frontend-standard/SKILL.md`.
